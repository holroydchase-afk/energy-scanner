# Contributing to Energy Scanner

Thanks for taking a look. This is a small portfolio project, so the process is light.

- **Found a bug or have an idea?** Open an issue using the template. Say what you expected and what happened, and which browser and phone or laptop you used.
- **Never attach a photo of a real person.** Describe the photo instead, or use the illustrated sample (See the aura demo). Issues here are public.
- **Want to change something?** Open an issue first for anything bigger than a typo, then send a small pull request that does one thing.
- **Before you push:** run `npm run lint`, `npm run typecheck` and `npm test`, and update `HANDOFF.md` if your change moves the work.
- **Keep it on-device.** Photos never leave the browser: no uploads, no analytics, no new third-party hosts.
- **Be kind.** Everyone here follows the [Code of Conduct](CODE_OF_CONDUCT.md).

Security problems go through [SECURITY.md](SECURITY.md), not a public issue.
