# Security

Please report a vulnerability privately: open the repo's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it.

You'll get a reply within a week. This is a small studio project, so there is no bug bounty, but credit is given in the fix if you'd like it.

Repo checks: gitleaks secret scanning over full history, a personal-data scan, dependency review on pull requests, CodeQL, and Dependabot (see `.github/workflows/security.yml` and `codeql.yml`).
